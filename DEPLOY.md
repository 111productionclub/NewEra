# Выкладка сайта

Сайт собирается в статические файлы (D-09): Node.js на хостинге не нужен, нужен любой веб-сервер, который отдаёт файлы.

## Сборка

Из папки `frontend/`:

```bash
pnpm install
pnpm build
```

Готовый сайт появится в `frontend/out/`. Адрес сайта по умолчанию `https://newerastore.ru` (используется в превью ссылок, `sitemap.xml` и `robots.txt`). Другой адрес задаётся при сборке: `NEXT_PUBLIC_SITE_URL=https://example.ru pnpm build`.

## Что выкладывать

Содержимое папки `out/` (не саму папку) в корень сайта на хостинге. Файл `.htaccess` скрытый, убедитесь, что он тоже скопирован.

## Настройка сервера

Страницы лежат как `about.html`, `products/biohazard.html`, поэтому серверу нужно открывать их по адресам без `.html` и отдавать `404.html` для несуществующих страниц.

**Apache:** всё уже сделано в `.htaccess` (нужен включённый `mod_rewrite`, на обычных хостингах он включён).

**nginx:**

```nginx
location / {
    try_files $uri $uri.html $uri/ =404;
}
error_page 404 /404.html;
```

## Проверка после выкладки

1. Открываются `/`, `/about`, `/products/biohazard`.
2. Обновление страницы товара (F5) не даёт ошибку.
3. Несуществующий адрес, например `/abc`, показывает страницу «Такой страницы нет».
4. Открываются `/robots.txt` и `/sitemap.xml`.
5. Ссылку на сайт отправить в VK или Telegram: должно появиться превью с логотипом (соцсети кешируют превью, первый показ может задержаться).
6. Кнопка «Купить в VK» копирует текст и открывает диалог сообщества.
